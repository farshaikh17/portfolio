# Farhan Shaikh — portfolio

A professional portfolio for technical operations, implementation, CRM/automation and AI-assisted systems delivery. The site explains responsibilities and decisions with evidence, rather than presenting Farhan as the sole author of all implementation code.

## Stack and architecture

Dependency-free static site generated by Node.js. Semantic HTML, responsive CSS, no client JavaScript, no database and no backend. Content is rendered at build time into `dist/`; case studies have their own routes. This keeps the site fast, portable and easy to review. Node 22 or newer; no install or environment variables are required.

## Local development

```sh
npm run build
npm test
npm run dev
```

Open http://127.0.0.1:4173. Edit `build.mjs` for content and shared layouts; edit `styles.css` for presentation. Rebuild after edits.

## Routes

- `/` — work, approach, leadership, experience, capabilities and contact
- `/work/miami-goes-local/` — professional/company case study
- `/work/parenthood/` — personal experiment case study
- `/404.html` — not-found experience
